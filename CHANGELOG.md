# Changelog

Notable changes are documented here. This project follows a lightweight form of [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and has not declared semantic-version stability.

## [Unreleased]

## [0.11.0] - 2026-09-11

### Added

- Stable portfolio documentation, architecture and API guides, guided demo and acceptance walkthroughs, measured evaluation results, and screenshot manifest.
- MIT license, security policy, contribution guidance, code of conduct, issue forms, pull request checklist, and generated OpenAPI drift validation.

### Changed

- Release framing now states non-production, privacy, trust-boundary, hosted-provider, and evaluation limitations explicitly.

## [0.10.0] - 2026-09-11

### Added

- Request hardening, process-local rate limits, secure browser response policy, recovery boundaries, non-root read-only containers, CI, CodeQL, and real-browser acceptance coverage.
- Deterministic 150-case evaluation, operational analytics, and sanitized administrator health visibility.

### Security

- Added trusted-host checks, bounded request identifiers, safe unhandled errors, sensitive-response cache controls, and dependency auditing.

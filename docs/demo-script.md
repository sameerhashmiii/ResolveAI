# 90-Second Demo Script

Use a fresh local Compose stack. All names and systems below are fictional.

| Time | Action | Point to make |
|---:|---|---|
| 0:00 | Open <http://localhost:3000>, select **Start 90-second guided demo** | Credential-free synthetic analyst session; local demo only |
| 0:10 | Select **Continue guided demo** | The workflow begins with a prefilled but still human-submitted ticket |
| 0:15 | Review the Dallas, PayrollPro, fictional requester, and device fields | Synthetic context drives the curated deterministic path |
| 0:20 | Create the ticket | No analysis or action starts automatically |
| 0:30 | Create the ticket and select **Analyze ticket** | Category signals are validated; priority is deterministic policy, not a model choice |
| 0:40 | Select **Start investigation** | LangGraph runs bounded read-only tools over synthetic persisted evidence |
| 0:52 | Select **Generate assessment** | Observations appear before a probable, unconfirmed inference |
| 1:02 | Open **Show Me Why** | Citations and confidence factors are auditable; confidence is evidence coverage, not accuracy |
| 1:12 | Approve the recommendation with reason `Evidence and bounded guidance reviewed by the demo analyst` | AI guidance requires an attributable human decision |
| 1:22 | Generate, review, and approve the requester response | The product explicitly says approval did not send it |
| 1:30 | If time permits, add a resolution summary and resolve | Resolution records workflow state only; no remediation or delivery occurred |

If a workflow takes longer than the time box, narrate its queued/running state and continue with a ticket prepared earlier. Do not describe synthetic evidence as live monitoring or the probable cause as confirmed.
